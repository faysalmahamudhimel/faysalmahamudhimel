### What I Do

**Frontend development, built with care.** I build responsive and interactive websites using HTML, CSS and JavaScript. I focus on clean UI, smooth interactions, and user-friendly experiences that work across devices.

**Useful tools, real-world solutions.** I develop web-based tools and CSE-focused applications through projects like MyCalcLab. My goal is to turn practical ideas into accessible, easy-to-use solutions that solve real problems.

**Learning by building.** I explore programming, object-oriented design, and C++ while expanding my knowledge of data structures and algorithms. I believe in learning through hands-on projects, writing better code, and continuously improving my development skills.
